# neXora : CA SPECIAL

GitHub/Render-ready Node + Express wrapper around the current self-contained CA quiz HTML.

## Local run

```bash
npm install
npm start
```

Open `http://localhost:3000`.

Health check: `http://localhost:3000/health`

## Render

Create a **Web Service** from this repository.

- Build Command: `npm install`
- Start Command: `npm start`
- Node: 20+

Render provides the `PORT` environment variable automatically.

## Frontend

The existing quiz application is intentionally kept as `public/index.html` so the question bank and current interaction logic are not regenerated by the server wrapper.

For future production upgrades, authentication, user progress, history synchronization and revision-bank persistence should move to server/database APIs rather than storing credentials or durable user data in the browser.
